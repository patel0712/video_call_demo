Objective
Evaluate your ability to:
● Integrate real-time video SDKs (Amazon Chime SDK preferred, but
Agora/Twilio/WebRTC also acceptable).
● Work with REST APIs.
● Design an app that’s close to store-ready (Play Store / App Store).
● Demonstrate best practices in architecture, state management, and error handling.
Problem Statement
Create a Flutter application with the following requirements:
1. Authentication & Login Screen
● A simple login screen with fields for email and password.
● Add basic validation (e.g., empty fields, email format).
● Mock authentication with a fake REST API (you can use ReqRes API or hardcoded
credentials).
2. Video Call Screen (SDK Integration)
● After logging in, navigate to a Video Call screen.
● Implement one-to-one video calling using Amazon Chime SDK (preferred) or any
RTC SDK (Agora, Twilio, WebRTC).
● Requirements:
○ Join a meeting using a meeting ID (hardcoded is fine).
○ Show local camera stream.
○ Show the remote participant’s video (use a second device/emulator for
testing).
○ Mute/unmute audio & enable/disable video buttons.
● Screen Share feature during video call.
3. User List Screen (REST API Integration)
● Create a simple screen that fetches a list of users from a FAKE REST API.
● Display users in a scrollable list with avatar + name.
● Cache results locally so that list works in offline mode.
4. App Lifecycle & Store-Readiness
● Add a splash screen and app icon.
● Prepare the app for deployment:
○ App Versioning
○ Configure Android & iOS app signing (debug keys are fine).
○ Add required permissions (camera, microphone, internet).
● Include instructions in README on how to build/run the app.
Bonus (Optional, but Valuable)
● Implement external camera support (if supported by chosen SDK).
● Add push notifications for incoming video calls (mocked).
● Use a proper state management solution (e.g., Bloc, Riverpod, Provider).
● Set up a CI/CD pipeline (GitHub Actions, Bitrise, or similar).
Technical Requirements
● Use Flutter (latest stable version).
● State management is up to you, but it must be consistent and clean.
● Video SDK: Amazon Chime SDK preferred, but alternatives are acceptable.
● Must handle camera & microphone permissions gracefully.
● App should not crash on orientation change or backgrounding.
Deliverables
● Source code in a GitHub/GitLab repository (public or private with access).
● Clear README with:
○ Build & run instructions.
○ SDK setup/configuration steps.
○ Notes on assumptions & limitations.
● APK/IPA build (optional but preferred).
Evaluation Criteria
● Feature Completion (Meets requirements).
